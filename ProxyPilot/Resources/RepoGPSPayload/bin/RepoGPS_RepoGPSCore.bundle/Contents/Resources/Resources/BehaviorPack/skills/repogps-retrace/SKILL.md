# Retrace

Read the closest repository instructions, branch and worktree state, current plans, recent durable history, and the latest handoff. Distinguish selected, configured, stored, and live evidence. Do not edit, test, commit, push, deploy, or write durable state.

Return a compact orientation card containing repository, branch, worktree condition, instruction hierarchy, active work, last verified state, risks, and the next safest action.
